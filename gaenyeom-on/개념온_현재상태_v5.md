# 2. 화면 구조

## 전체 흐름

```
로그인 → 목차 → 단원 관계지도 → 개념어 카드
```

**로그인 · 목차 · 관계지도는 아직 안 만들었습니다.**
관계지도는 코덱스에서 만드시기로 했습니다.

## 개념어 카드 · 다섯 화면

```
① 현상       그림을 보고 차이를 찾는다 → 낱말 칠하기 → 왜 물음
② 원리       현상에 숨겨진 원리는 무엇일까? → 물음 써 보는 칸
③ 비주얼 싱킹  어떻게 나타낼까? → 선생님 그림 → 공책에 그리기 → 사진
④ 어휘 돋보기  한자 뜻은 무엇일까? · 한자가 있는 카드만
⑤ 설명하기    물음 셋에 답 → 답안 예시 → 내가 쓴 것과 비교
```

**한 화면에 물음 하나**입니다. 물음이 없는 화면은 안 나옵니다.
힘의 크기는 한자가 없어 **넷**, 힘의 평형은 **다섯**입니다.

### 개념의 네 부분

**물음은 아이가 읽는 말, 라벨은 아이가 익히는 말**입니다. 둘을 나란히 둡니다.

| 화면 · 물음 | 라벨 · 어른 말 |
|---|---|
| 무슨 일이 일어나고 있어? | **현상** |
| 현상에 숨겨진 원리는 무엇일까? | **원리** |
| ○○, 어떻게 나타낼까? | **표현** |
| — | **이름** |

**어른 말은 설명하지 않습니다.** 하는 자리에 이름표를 붙여 익히게 합니다.
「비주얼 싱킹」과 「어휘 돋보기」도 화면 위 딱지로 먼저 만나고,
⑤에서 「비주얼 싱킹을 떠올리면서」로 다시 만납니다. 한자를 다루는 방식과 같습니다.

### ① 현상 화면 · 미션 둘

```
미션 1  개념어마다 다른 물음      「잘 모르겠으면 힌트」는 눌러야 열림
        [차이점을 찾았어]
미션 2  차이를 나타내는 낱말을 눌러 봐   형광펜으로 칠해진다
        [체크 완료] → 코인 두 개
        왜 그런 차이가 생겼을까?
```

**미션 1 문구는 개념어마다 다릅니다.** 다 차이 비교가 아닙니다.

| | |
|---|---|
| 차이 | 힘의 크기 · 무게 · 속력 |
| 반대 | 힘의 방향 |
| 자리 | 작용점 |
| 순서 | 탄성력 |
| 공통점 | 힘의 작용 |
| 같은 것 | 질량 — 같다는 게 답이라 차이를 찾으라 하면 반대로 간다 |

**차이점을 찾고 나면 그림이 작아집니다.** 화면 높이의 38%까지 줄어 한 화면에 다 들어옵니다.

### ② 원리 화면 · 물음 써 보는 칸

```
더 궁금한 게 생겼어?
물음이 안 떠오르면 육하원칙으로 시작해 봐.
[누가] [언제] [어디서] [무엇을] [어떻게] [왜]
공책 줄이 그어진 칸 일곱 줄
```

단추를 누르면 그 말이 칸에 들어갑니다. 개념어마다 따로 저장됩니다.
**예시는 안 보여 줍니다.** 보여 주면 아이가 그중 하나를 고릅니다.
아이들이 쓴 것을 보고 나서 정합니다.

### ⑤ 설명하기

```
그림과 상황을 떠올리면서   1 · 무슨 일이 있었지?
한자를 떠올리면서        2 · 그 개념을 뭐라고 하지?
비주얼 싱킹을 떠올리면서   3 · 원리는 무엇이지?
```

**떠올릴 곳을 짚어 줍니다.** 세 물음이 앞의 세 화면을 하나씩 가리킵니다.
한자가 없는 카드는 「낱말을 떠올리면서」로 나옵니다.

**글쓰기 과제가 아닙니다.** 「한 문단으로 써 봐」를 뺐습니다.
**답안 예시**를 보고 **내가 쓴 것과 비교**하는 자리입니다.

답안 예시는 세 줄에 라벨이 붙습니다.

```
이름  ○○은 …야
원리  ( 인과 · 까닭 → 결과 )  …
예시  …가 그 예야
```

**원리 줄에만 구조를 표시합니다.** 인과 · 조건 · 순서 · 대조 넷 중 하나이고,
옆에 뜻풀이를 답니다. 세 줄에 다 붙이면 구조 이름을 외우는 공부가 됩니다.
힘 단원은 인과 열, 조건 넷입니다.

**물음 셋과 답안 셋이 어긋납니다.** 물음은 예시 · 이름 · 원리, 답안은 이름 · 원리 · 예시입니다.
Q1의 「무슨 일이 있었지」가 곧 예시라서 빠진 것이 없습니다.

### 게임 요소

```
코인   형광펜 체크 완료 2개 + 설명하기 체크 3개 = 카드 하나에 5개
소리   쨍그랑. 코드로 만든다. 음원 파일 없음
한자   눌러서 뒤집으면 훈음과 쓰임이 나온다
```

**코인은 맞혀서 주는 게 아니라 해 봐서 줍니다.**
**하나씩 주지 않습니다.** 하나씩 주면 다음 코인을 기대하며 아무 낱말이나 누릅니다.

### ④ 스스로 물어보기 자리

**뺐습니다.** `const USE_SELF=0` 을 `1` 로 바꾸면 돌아옵니다. 데이터는 다 살아 있습니다.

### 글자 크기 · 네 층

```
--fq  29px 600  메인 질문     명조
--fm  19px 500  미션         명조
--fb  17px 400  본문         고딕
--fg  15px 600  학습 가이드    고딕
```

### 글꼴 · 둘

```
물음 · 미션   Noto Serif KR    명조
그 밖 전부    IBM Plex Sans KR  고딕
```

**명조 제목 + 고딕 본문**입니다. 프리텐다드는 굵고 딱딱해서 뺐고,
나눔스퀘어라운드는 CDN이 막혀 안 받아졌습니다. **구글 폰트에서만** 고릅니다.

**명조 제목은 크게.** 가로획이 얇아 작으면 흐려집니다. 자간을 조이고 줄 간격을 좁혀
덩어리로 뭉치게 하고, 본문은 반대로 줄 간격을 넓혀 밀도를 갈랐습니다.

### 강조

```
본문 강조   연노랑 형광펜 · 글자는 검정
물음 강조   연초록 형광펜
```

**빨간 글씨를 뺐습니다.** 「틀린 글자」나 「경고」로 읽혔습니다.

### 조건 카드

`①②③` 으로 시작하는 줄은 **번호 카드**가 됩니다. 글에서 자동으로 잡습니다.
번호를 한 줄에 몰아 쓰면 카드가 하나로 뭉치니 **줄을 갈라** 씁니다.

### 색

**개념어의 3분류 색이 카드 안까지 이어집니다.**

```
그림을 꼭 봐야 해  초록    꼭 알아야 해  빨강    헷갈리기 쉬워  노랑
```

**강조 낱말만 노랑 고정**이고, 하단 버튼은 초록입니다.

# 3. 2026-08-15에 한 것

## VTS 열셋을 마저 바꿨습니다

**Ⅴ 힘의 작용 14개가 전부 VTS입니다.** 탄성력 하나만 되어 있던 것을 마저 했습니다.
개념어마다 `seeQ · seeHint · seeA · whyQ · whyHint · whyA · nameQ · nameA · more`를 새로 썼고
모범 문단을 **「이름 → 원리 → 예시」 세 줄**로 다시 썼습니다.

| 칸 | 규칙 |
|---|---|
| `seeQ` | **열넷 다 「무슨 일이 일어나고 있어?」**로 고정했습니다 |
| `seeHint` | 열넷 다 같은 문장입니다 |
| `seeA` | 그림에 **보이는 것만** 씁니다. 이름을 먼저 말하지 않습니다 |
| `whyQ` | 눈에 안 보이는 것을 묻습니다. 물음표로 끝냅니다 |
| `whyA` | 원리를 말하되 **이름은 아직 말하지 않습니다** |
| `nameQ` | 「~를 뭐라고 한다고 했지?」 — ①에서 배운 것을 꺼냅니다 |
| `more` | 방향 · 단위 · 조건 같은 곁가지를 여기로 몰았습니다 |

**`seeQ`를 고정한 이유** — VTS는 늘 같은 물음으로 시작합니다.
물음이 매번 달라지면 아이가 물음을 읽느라 그림을 안 봅니다.

**그림이 「없음」인 여섯 개는 `whyQ`에 장면 한 줄을 붙였습니다.**
②를 건너뛰면 아이가 아무것도 못 본 채 ③에 닿기 때문입니다.
그림이 생겨서 ②가 켜지면 그 한 줄은 빼야 합니다. **잊지 마십시오.**

**`ask`와 `cond`는 안 지웠습니다.** 화면에는 안 나오고 데이터로만 남아 있습니다.

## 교과서 문장을 뺐습니다 · 저작권

| 어디 | 무엇 | 어떻게 |
|---|---|---|
| Ⅲ 열 | `book` **13곳** | 지우고 「꼭 넣어야 해」 낱말(`key`)로 바꿨습니다 |
| Ⅴ 힘 | 「」 인용 **3곳** | 힘의 평형 · 합력 · 힘의 작용. 우리 말로 다시 썼습니다 |
| 화면 | 「시험에 이대로 나와」 블록 | **「한 문장으로 정리하면」으로 바꿨습니다** |
| 화면 | 「교과서 말을 아직 안 옮겼습니다」 | 「「꼭 넣어야 해」 낱말을 아직 안 뽑았습니다」로 |

### 정의 문장은 우리가 씁니다 · `def`

교과서 문장을 빼기만 하면 **시험에 나오는 말을 만날 자리가 사라집니다.**
그래서 낱말만 남기지 않고 **정의 한 문장을 우리가 새로 썼습니다.**
원고 30개 · 낱말 37개 전부에 `def` 칸이 있습니다.

```
def 쓰는 법
 한 문장. 단위나 조건은 뒤에 짧게 붙인다
 교과서 어순을 따라가지 않는다. 무엇으로 정의할지부터 다르게 잡는다
 시험에 나오는 낱말은 그대로 쓴다 — 이 칸만 예외다
 <b> · <br> 같은 태그를 넣지 않는다
```

**「쉽게 쓴다」는 원칙의 예외는 이 칸 하나뿐입니다.**
쉬운 뜻은 `words`에 있고, 시험 말은 `def`에 있습니다. 화면에서 위아래로 만납니다.

**Ⅳ · Ⅵ · Ⅶ에는 옮겨 놓은 교과서 문장이 없었습니다.**
Ⅳ는 증발 하나, Ⅶ은 행성 하나뿐이고 둘 다 `book` 칸이 없습니다. Ⅵ은 원고 자체가 없습니다.
**할 일이 없어서 안 한 것이지, 빠뜨린 것이 아닙니다.** 원고를 쓸 때 처음부터 낱말로 쓰면 됩니다.

## 비주얼 싱킹 자료를 붙였습니다 · 2026-08-15

코덱스에서 만든 `force-concept-sketch-board`를 앱에 넣었습니다.
**⑤ 그려 보기의 「선생님 그림」 자리**입니다.

> **② 무슨 일의 장면 그림과 다릅니다.** 그림 두 벌이 한 카드에 따로 들어갑니다.
> 데이터도 따로입니다. 선생님 그림은 `SKS` · `SKC`, 장면 그림은 `SCS` · `SCN`.

### ① 장면 그림 · 여섯 장 완성

```
다 됨   1 힘의 크기 · 2 힘의 방향 · 4 힘의 평형 · 6 질량 · 7 무게
       8 중력 · 10 마찰력 · 11 부력 · 12 힘의 작용 · 13 운동
남음   5 합력 · 9 탄성력 · 14 속력
다시 잡을 것  3 작용점 — 위에서 본 문이 안 와닿음. 시소 쪽으로
```

**만드는 차례입니다.**

```
1  개념어마다 새 대화를 연다
2  「① 규칙」을 붙여 넣는다. 참고 사진이 있으면 같이 올린다
3  첫 장을 붙여 넣는다
4  같은 대화에서 「② 이어 그리기」 + 둘째 장
5  Claude 가 재서 확인한다. 자 선 위쪽만 재야 한다
6  Claude 가 붙이고, 앱에 넣고, 그 카드 글을 그림에 맞춰 다시 쓴다
```

**그림이 바뀌면 그 카드 글 전체를 다시 봅니다.** 두 번 빠뜨렸습니다.

**「~만 고쳐 줘」는 조심합니다.** 고칠 것만 말하면 나머지가 무너집니다.
잘 나온 부분까지 「같아야 할 것」으로 다시 적어 줍니다.

**자리가 조금 어긋난 것은 Claude 가 옮깁니다.** 지피티는 부분 수정을 못 합니다.
같은 그림을 그대로 다시 내놓습니다. 그림 자체가 틀렸을 때만 다시 뽑습니다.

**끝난 카드의 지시문은 프롬프트 파일에 최종본으로 남깁니다.**
「다 됐습니다」로 표시해 두었습니다. 다시 뽑을 일이 있으면 그대로 쓰면 됩니다.

### 선생님 그림이 화면 맨 위로 갔습니다 · 2026-08-15

```
전 대본 → 공책에 그려 봐 → 선생님 그림
후 선생님 그림 → 대본 → 공책에 그려 봐
```

「모르면 기다리지 말고 바로 예시를 보여 준다」는 1장 원칙을 따릅니다.
문구도 「다 그린 뒤에 대 봐」에서 **「이렇게 그리면 돼」**로 바꿨습니다.

**⑥ 설명하기와는 반대 순서입니다.** 글은 먼저 보이면 따라 읽기가 되지만,
그림은 먼저 봐도 손으로 다시 그려야 해서 베끼기가 되지 않습니다.

```
장 세 개를 통째로 넣고 개념어마다 viewBox로 잘라 씁니다
자르기 좌표는 index.html 안 SKC 표에 있습니다
SKS.a 여덟 칸 · SKS.b 다섯 칸 · SKS.c 탄성력 한 칸
```

| 무엇 | 어떻게 |
|---|---|
| 아래줄 자르기 | 운동 `0 400 800 400` · 속력 `800 400 800 400`으로 통일 |
| 탄성력 | **Claude가 그렸습니다.** 코덱스 것이 오면 `SKS.c`만 갈아 끼우면 됩니다 |
| `.divider` | 뺐습니다. 잘라 쓰면 잘린 자리에 반쪽 선이 남습니다 |
| `.panel-boundary` | 넣었습니다. 자르는 자리를 눈으로 잡을 때 씁니다 |
| 색 | 앱 색으로 이었습니다. 힘 화살표는 `--must`, 물은 `--pic` |

### 표현용 다섯을 켰습니다 · 2026-08-15

질량 · 무게 · 마찰력 · 운동 · 속력의 `pv`를 **0에서 1로** 바꿨습니다.
설계표에서 「안 그린다」던 것인데, 선생님 그림 다섯 장이 사장되는 게 더 아까워서입니다.
**이제 열넷 다 ⑤ 화면이 있습니다.**

**그리기 대본도 다섯 개 새로 썼습니다.** 없으면 「대본을 아직 안 썼습니다」가 뜹니다.
다섯은 처음부터 **선생님 그림에 맞춰** 썼습니다. 어긋난 다섯과 다릅니다.

# 6. 사례 고르는 규칙 · 2026-08-15 확정

**적용 범위** — 장면 그림 · 도입 · 예시 · 모범 문단의 세 번째 줄. **사례가 들어가는 모든 자리**입니다.

## 고르기 전에 넷을 묻는다

```
1 겪어 봤나   중학교 1학년이 몸으로 해 본 일인가
2 잘 보이나   그 개념어 하나만 달라지는 두 장면을 만들 수 있나
3 안전한가    실제로 하면 다치지 않는가. 그렇게 하는 사람을 본 적 있나
4 궁금한가    「어? 왜지?」 하고 멈칫할 만한가
```

**3번에서 걸린 것이 그네였습니다.** 「같은 세기, 방향만 반대」를 만들려고
그네를 앞에서 미는 장면을 썼는데, 그네가 되돌아오면서 미는 아이를 칩니다.
**아이한테 하지 말라고 가르치는 짓을 그림으로 보여 주는 꼴**이었습니다.

## 억지로 대비를 만들지 않는다

**한 물체를 반대로 두 번 미는 상황은 원래 잘 없습니다.**
없는 상황을 만들면 어딘가 반드시 무리가 납니다.

대비가 자연스럽게 안 나오면 **사례를 바꿉니다.** 장면을 비틀지 않습니다.
힘의 방향은 그래서 그네를 버리고 **청소 시간에 책상 옮기기**로 갔습니다.
방향은 「한 물체를 반대로 두 번」이 아니라 **「밀어서 간 쪽이 다르다」**로 보여 주면 됩니다.

## 검산하는 법

사례를 정한 뒤 **그 장면을 머릿속에서 끝까지 돌려 봅니다.**
그네는 「밀었다」에서 멈추면 멀쩡한데, **되돌아오는 데까지 돌리면** 사고가 납니다.

```
그다음에 무슨 일이 일어나는가
그걸 교실에서 시켜도 되는가
실제로 하는 사람을 본 적이 있는가
```

## 그림에 붙는 규칙

**Ⅴ 힘에서 굳힌 것입니다. 나머지 단원에도 그대로 씁니다.**

```
기준선을 넣는다        0 눈금 · 처음 자리 점선. 없으면 무엇이 달라졌는지 못 잰다
달라지는 원인은 하나    그 원인에서 나온 결과는 여럿이어도 된다
개념어 이름을 안 넣는다  ①은 아이가 이름을 맞혀 가는 자리다
숫자는 실제 값으로      4초에 80 m는 사람이 못 달린다
크기는 양쪽을 다 말한다  한쪽만 말하면 다른 쪽을 줄여 버린다
눈금 간격을 검산한다    첫 칸이나 마지막 칸만 다르게 나온 적이 여러 번 있다
남녀를 번갈아 쓴다      홀수는 남자, 짝수는 여자
아이 머리는 모두 검은색  안 쓰면 갈색으로 나온다
```

### 재는 그림에서

다만 **끌린 자국 · 굴러간 자국 · 파인 자리는 예외**입니다. 바닥에 실제로 남는 흔적이라 넣습니다.

**「그림자를 넣지 않는다」**도 이유가 있습니다.
두 장을 나란히 붙일 때 그림자 방향이 조금만 달라도 어긋나 보입니다.

**「숫자와 도구가 잘 보이게」**는 자 눈금 때문입니다.
그림 모델은 자를 장식으로 봐서 마지막 칸을 짧게 그립니다. 실제로 15% 짧게 나온 적이 있습니다.

## 실사에는 화살표를 넣지 않는다 · 2026-08-15 확정

```
② 장면 그림   실사. 화살표 없음. 겪어 본 일과 결과만 보여 준다
⑤ 선생님 그림  도식. 화살표로 크기 · 방향 · 작용점을 정확히 나타낸다
```

**한때 A판 B판으로 나눠 실사에도 화살표를 얹으려 했는데 접었습니다.**

실사에는 사람과 물건이 있어서 **「닿았나 안 닿았나」가 늘 걸립니다.**
공을 찬 뒤 그림에 발에서 공으로 화살표를 그으면
**「굴러가는 공을 계속 밀고 있다」**가 됩니다. 중1이 가장 많이 갖는 오개념입니다.

제대로 그리려면 **닿은 순간**을 따로 그려야 하는데, 그러면 ②와 ③의 장면이 달라져
아이가 시간을 거꾸로 돌려야 합니다.

도식에는 네모와 화살표뿐이라 이 문제가 없습니다. **애초에 도식을 쓰는 이유가 그것입니다.**
②에서 본 축구공 장면을 머릿속에 두고 ⑤의 네모를 보면, 아이는 그 네모가 공인 줄 압니다.

# 7. 문장 규칙

## VTS 칸 쓰는 법 · 2026-08-15 확정

```
seeQ 열넷 다 「무슨 일이 일어나고 있어?」. 바꾸지 않는다
seeA 그림에 보이는 것만. 이름을 먼저 말하지 않는다
whyA 원리까지만. 이름은 nameQ에서 꺼낸다
model 세 줄. 이름 → 원리 → 예시. 첫 줄은 개념어로 시작한다
checks 셋. 무엇인지 · 원리 · 예시. 물음 셋과 짝을 맞춘다
```

## 도입 쓰는 법

```
두세 문장으로 장면을 세운다. 한 문장으로 압축하지 않는다
마지막 한 줄이 질문이다. 물음표로 끝낸다
오개념을 도입에 넣지 않는다
그림 없이 읽어도 장면이 떠올라야 한다
```

**사례 기준은 직관성 → 교과서 변형 → 호기심 순**입니다.
**고르기 전에 6장의 「사례 고르는 규칙」 넷을 먼저 묻습니다.**

## 문장 원칙 열둘

```

전하게 대구보다 뜻 · 오개념 목록에 있는 것만 부정 · 소리 내어 읽기
```

## 학생 화면에서 안 쓰는 말

```
견주다   →  찾아봐 · 대어 보고 · 비교해 봐
화살촉   →  화살표 · 화살표가 가리키는 쪽
머릿속으로 말해 봐  →  시킬 수 없는 일이다. 무엇을 할지로 쓴다
```

**중학생이 쓰는 말인지가 기준입니다.** 어른 말은 라벨로만 씁니다.

## 저작권 넷

```

실험 수치를 그대로 쓰지 않는다
사진 · 그림 · 삽화는 참고만 한다
교과서는 사실 확인에만 쓴다. 표현은 우리가 쓴다
```

**규칙은 모든 화면의 모든 문장에 적용합니다.**
표 칸 이름 · 버튼 글자 · 체크 문구까지 포함합니다.
