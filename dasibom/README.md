# 다시봄

**글로온**(글로, 생각을 켜다)의 학습 앱입니다.

중학교 1학년 학생이 **수업 당일 집에서 혼자 복습**하는 도구로,
단원 지도로 큰 그림을 먼저 잡고, 교과서를 읽으며 빈칸을 채우고,
자기 말로 설명한 것을 AI가 진단합니다.

## 네 단계

**지도 보기 → 개념 읽기 → 개념 말하기 → 개념 확인하기**

보기만 하면 안 남습니다. 읽은 것을 **자기 말로 되돌려 말해야** 자기 것이 됩니다.

## 빠른 시작

- 화면: `app/index.html` 을 브라우저에서 엽니다. 설치할 것 없습니다.
- 인쇄: `print/science/`, `print/social/` 안의 워크북 PDF를 뽑습니다.
  전부 세로 A4입니다. **1장(단원 지도)만 종이를 돌려서 씁니다.**
- 학부모께 보여 드릴 때: `print/학부모_안내.pdf` (A4 1장)
- 전화·줌으로 설명할 때: `print/다시봄_앱소개.pdf` (가로 A4 14장)

## 폴더

```
app/
  index.html        빌드 결과 — 이 파일을 열면 됩니다
  _template.html    화면 코드 원본
  data/             과목별 데이터
  build_app.py      템플릿 + 데이터 → index.html
print/
  science/          과학 인쇄물 + 빌드 스크립트
  social/           사회 인쇄물 + 빌드 스크립트
docs/
  HANDOVER.md       설계 문서
check.js            데이터 검수 스크립트
```

## 지금 들어 있는 단원

| 과목 | 단원 | 개념 카드 | 문항 |
|---|---|---|---|
| 과학 | 힘의 작용 | 5 (힘의 표현은 여섯 단계 카드, 네 힘은 누가·누구에게·어느 쪽으로) | 6 |
| 사회 | 인간과 사회생활 | 6 (소제목별) | 6 |

## 개념 카드 두 가지

| 카드 | 구조 | 지금 쓰는 곳 |
|---|---|---|
| 빈칸 카드 | 짐작해서 채우고 → 정답과 대조 | 과학 네 힘, 사회 여섯 소단원 |
| 여섯 단계 카드 | 장면 → 이름 → 구조 → 비교 → 적용 → 설명 | 과학 「힘의 표현」 (시범) |

여섯 단계 카드는 데이터에 `card: "six"` 를 주면 켜집니다.
자세한 형식은 [docs/HANDOVER.md](docs/HANDOVER.md) 12-5에 있습니다.

## 과목을 추가하려면

1. `app/data/` 에 데이터 파일을 하나 만듭니다
2. `cd app && python3 build_app.py` — 자동으로 찾아 합칩니다
3. **`node check.js` 를 돌립니다**

자세한 절차는 [docs/HANDOVER.md](docs/HANDOVER.md) 12장에 있습니다.

> 화면 파일을 복사해서 새 과목을 만들지 마세요.
> 복사본이 생기면 이전 과목의 문구가 남고, 화면을 고칠 때마다 두 군데를 고쳐야 합니다.
>
> `index.html` 은 빌드 결과라 직접 고치면 다음 빌드에서 지워집니다.
> 화면을 고칠 때는 `_template.html` 을 고치세요.

## 이어서 작업하려면

**[docs/HANDOVER.md](docs/HANDOVER.md)** 를 먼저 읽으세요.
AI에게 이어서 시킬 때는 그 문서를 통째로 붙여넣으면 맥락이 복원됩니다.

- 2장 설계 원칙 — 트리거, 하나의 문법, 되돌아오는 고리
- 3장 디자인 시스템 — 색·글자 크기·여백·글쓰기 기준
- 6장 주의사항 — 질량/무게 구조, 저작권, 교과서 충돌 처리
- 12·13장 — 과목 추가 절차, 문항 만드는 기준

## 주의

- 교과서 문장·삽화·쪽수를 넣지 않습니다. 출판사 중립으로 만듭니다.
- 성취기준 코드는 아직 확인되지 않았습니다. NCIC에서 확인 후 채워야 합니다.
- 인쇄물에 이모지를 넣지 않습니다. PDF에서 깨집니다.
