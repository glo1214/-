# 리셋 시트 (Reset Sheet) · 재수생용

공부가 안 될 때 · 낮잠 · 밤에 잠이 안 올 때, 지금 상태를 답안지(OMR) 마킹하듯
고르고 대처로 이어지는 단일 화면 웹앱입니다.

세 갈래로 나뉩니다.

- **01 공부가 안 돼요** — 컨디션 체크인 후 몸 · 감정 · 생각 중 원인을 골라
  1·2·3교시로 타고 들어가고, 회복 정도와 다음 한 걸음을 기록합니다.
- **02 10분만 자고 올게요** — 파워냅 타이머와 "깨워달라"는 부탁 문장 복사.
- **03 밤에 잠이 안 와요** — 몸 다독이기(호흡 · 만져주기 · 감사하기)와
  CBT-I 흐름(걱정 내려놓기 · 근육 이완 · 생각 흐트러뜨리기).

기록은 브라우저 `localStorage`에 저장됩니다.

## 기술 스택

- React 18 + Vite
- Tailwind CSS

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## 구조

| 파일 | 설명 |
| --- | --- |
| `src/App.jsx` | 앱 전체 (화면 · 흐름 · 컴포넌트) |
| `src/main.jsx` | 진입점 + `window.storage` → `localStorage` 심(shim) |
| `src/index.css` | Tailwind 지시문 |

원본 컴포넌트는 Artifacts 환경의 비동기 `window.storage` API를 사용합니다.
일반 브라우저에서는 그 API가 없으므로 `src/main.jsx`에서 `localStorage` 기반
심을 주입해 기록이 실제로 유지되도록 했습니다.
